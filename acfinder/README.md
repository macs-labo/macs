Agricultural Chemicals Finder Browser Edition / Copyright &copy; 2025-2026 TEAM ACFinder / Lisenced under the MIT Lisence

## 本プロジェクトについて
携帯農薬検索実験室の農薬情報データベース（MacsDB）をローカルにダウンロードして、検索及びその結果をテーブル表示するためのブラウザアプリです。
